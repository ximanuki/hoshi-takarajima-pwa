# 見積ルール（過去データから復元）: blind-print

過去の見積と矛盾しない最小のルールです。金額はすべて**税抜・端数処理前**の積算で、最後に掛率・最低料金・端数処理を適用します。
ルールの数値は決定的な計算（LLM不使用）で求め、履歴の見積で1円単位まで検算しています。

- 対象: 2,434件（2022-10-01〜2025-09-30）
- **2,434件中2,162件を円単位で再現**（88.8%）

## 計算の順序

1. 区分ごとの積算（下の表の合計。改定日以降は新しい単価）
2. 掛率（得意先・条件による割引／割増）を掛ける
3. 掛率の対象外の項目（「掛率の後に加算」と書いたもの）を足す
4. 最低料金を適用
5. 端数処理: 100円未満切り捨て
   - 例外: rep=佐藤 は 10円未満切り捨て
6. 税込表示の見積は 税抜額×(1+税率) の円未満切り捨て
