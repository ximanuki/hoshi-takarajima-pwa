- 数値は取得したときの公表値です。手で数値を作ったり補ったりはしていません。うまく取得・照合できなかった系列は収録せず、下の「収録しなかったもの」に理由を書いています。
- 取得日時：2026-10-16 16:15〜16:17 UTC（日本時間 2026-10-17 01:15〜01:17）。統計は後から訂正されることがあるため、実際に使う前には最新の公表値を確認してください。

- **収録系列**（系列コード）：総平均 `PRCG20_2200000000`／総平均の前年比 `PRCG20_2200000000%`／パルプ・紙・同製品 `PRCG20_2200420001`／化学製品 `PRCG20_2200520001`／石油・石炭製品 `PRCG20_2200620001`／プラスチック製品 `PRCG20_2200720001`／鉄鋼 `PRCG20_2200920001`／非鉄金属 `PRCG20_2201020001`／金属製品 `PRCG20_2201120001`／電力・都市ガス・水道 `PRCG20_2202220001`

- **加工**：API の応答から系列コード・系列名・単位・値だけを取り出し、期間を `YYYY-MM` の形に直しました。値はそのままで、基準の付け替え・丸め・季節調整はしていません。
- **注意**：最新月は速報値です。日本銀行は公表のたびに直近数か月分を訂正することがあります（2026年9月速報では6月・8月分の一部が訂正されています）。類別指数の前年比は日本銀行が系列として出していないため、収録していません。

- 「サイトのご利用上の留意点等」（https://www.stat-search.boj.or.jp/info/notice.html ）：出所を明記すれば転載・複製できます。ただし、**商用目的で転載・複製する場合は、事前に日本銀行情報サービス局へ相談する**ことになっています。また、内容を日本銀行に無断で改変することはできません。
- 「API機能利用時の留意点について」（https://www.stat-search.boj.or.jp/info/api_notice.pdf ）：API を使ったサービスを公開する場合は、次のクレジット表示と、日本銀行調査統計局への連絡が求められています。

- このアプリは実行中に API を呼び出しません（API は、このスナップショットを作るときに一度だけ使いました）。それでも、念のため上記のクレジットを JSON の `credit_ja` に入れてあり、画面にも表示する想定です。

## 3. 地域別最低賃金（`minimum-wage.json`）

- **作成者**：厚生労働省
- **掲載ページ**：「地域別最低賃金の全国一覧」 https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/minimumichiran/
- **取得したファイル**：
  - 平成14年度から令和８年度までの地域別最低賃金改定状況（Excel） https://www.mhlw.go.jp/content/11200000/001756130.xlsx
  - 令和８年度地域別最低賃金全国一覧（PDF） https://www.mhlw.go.jp/content/11200000/001753404.pdf
- **取得日時**：2026-10-16T16:15:39Z
- **加工**：
  - Excel から、全国加重平均額（2002〜2026年度の全年度）と、47都道府県の2023〜2026年度（令和5〜8年度）の金額・発効年月日を取り出しました。
  - 全国加重平均額のうち平成29年度と令和8年度は、Excel のセル値が小数を含む計算値です。セルの表示書式（整数）に合わせて四捨五入し、848円・1,177円としました。令和8年度の1,177円は PDF の記載と一致します。
  - 都道府県名の全角スペースを除きました。`name_ja` は資料どおりの表記（「東京」「青森」など）で、`name_ja_full`（東京都・青森県など）と JIS 都道府県コード（01〜47）を付け加えています。発効年月日は `YYYY-MM-DD` 形式に直しました。
  - 令和8年度分には、PDF に記載された引上げ額・引上げ率（`increase_yen_official`、`increase_rate_pct_official`）を加えました。
- **照合**：令和8年度と令和7年度の金額、令和8年度の発効日・引上げ額について、Excel と PDF が47都道府県と全国加重平均のすべてで一致することを確認しました。
- **注意**：令和8年度の金額は、資料上「答申された改定額」です。取得した時点では、まだ発効日が来ていない都道府県があります（例：岩手・熊本は2026年12月1日、沖縄は12月2日）。発効日より前は前年度の金額が使われるので、画面では発効日を見て「発効済み／発効予定」を分けて表示してください。

## 4. 春季賃上げ（`shunto.json`）

- **作成者**：厚生労働省（政策統括官付 労使関係担当参事官室）
- **掲載ページ**：「令和８年 民間主要企業春季賃上げ要求・妥結状況を公表します」（2026年7月31日） https://www.mhlw.go.jp/stf/newpage_74889.html
- **取得したファイル**：第２表 民間主要企業における春季賃上げ状況の推移（PDF） https://www.mhlw.go.jp/content/12604000/001727594.pdf
- **取得日時**：2026-10-16T16:16:29Z
- **加工と照合**：第２表の PDF は、表が画像になっていて文字として取り出せません。そこで2012〜2026年の妥結額と賃上げ率を表から書き写し、次の2つと照合しました。
  - 労働政策研究・研修機構（JILPT）「早わかり グラフでみる長期労働統計」の表（Excel、同じ厚生労働省統計を機械で読める形にしたもの、https://www.jil.go.jp/kokunai/statistics/timeseries/html/g0402.html ）と全件一致。
  - 2025年・2026年分は、厚生労働省の報道発表の本文（妥結額18,629円→18,167円、賃上げ率5.52％→5.18％）とも一致。

  JILPT のサイトポリシーでは、著作権法上認められる場合を除いて、無断の複製・転載が禁止されています。そのため、JILPT の表はこの照合に使っただけで、リポジトリには含めていません。収録した値の出典は厚生労働省です。
- **収録しなかった列**：現行ベース（交渉前の平均賃金）と分散係数は、画像からの読み取りを別の資料で照合できなかったため入れていません。
- **注意**：集計対象は、資本金10億円以上かつ従業員1,000人以上の労働組合のある企業のうち、妥結額などを把握できた企業です（令和8年は428社）。妥結額・賃上げ率には定期昇給分が含まれます。大企業が中心の集計なので、中小企業の賃金の動きをそのまま表すものではありません。

## 公表資料の示し方について（一般的な情報）

**参照した資料**：内閣官房・公正取引委員会「労務費の適切な転嫁のための価格交渉に関する指針」（令和5年11月29日策定、令和8年1月1日改正）
https://www.jftc.go.jp/dk/guideline/unyoukijun/romuhitenka.html

（公正取引委員会のサイトは、この作業環境からは取得できませんでした（HTTP 403）。そのため、改正後の本文は、国土交通省近畿運輸局が掲載している写し https://wwwtb.mlit.go.jp/kinki/content/000370897.pdf で確認しました。）

指針に書かれていることのうち、根拠資料に関係する部分を紹介します。

- **根拠資料には公表資料を使う**：受注者は、労務費が上がっていることを示す根拠資料として「最低賃金の上昇率、春季労使交渉の妥結額やその上昇率などの公表資料を用いること」とされています（受注者としての行動②）。例として、都道府県別の最低賃金とその上昇率、春季労使交渉の妥結額とその上昇率、公共工事設計労務単価、一般貨物自動車運送事業に係る標準的な運賃が挙げられています。さらに参考として、毎月勤労統計調査の賃金指数・給与額とその上昇率、消費者物価指数、ハローワークの求人票や求人情報誌に載っている同業他社の賃金も挙げられています。
- **発注者は尊重する**：発注者には、受注者が公表資料を使って示した希望価格を「合理的な根拠があるものとして尊重すること」が求められています。全額を受け入れない場合は、その根拠や合理的な理由を説明することが求められています（発注者としての行動③）。
- **社内の原価の出し方**：指針は、自社のコスト構造を相手に見せると、かえってコストを査定され、原価を下げるよう求められるおそれがあることに触れています。そのうえで、根拠資料が必要な場合は公表資料を使うべきだとしています。このため、申入書の参考資料欄は公表統計を中心にし、社内の原価の内訳は必要な範囲にとどめる、という作り方が考えられます。
- **希望価格は自分から示す**：発注者から価格を示されるのを待たずに、自分から希望価格を示すこととされています（受注者としての行動④）。交渉のタイミングの例として、「定期の価格改定や契約更新に合わせて」「最低賃金の引上げ幅の方向性が判明した後」などが挙げられています（受注者としての行動③）。指針の別添には、価格交渉を申し込むときの様式の例も載っています。
- **交渉の記録を残す**：価格交渉の記録を作り、発注者と受注者の双方で保管することが挙げられています（発注者・受注者共通の行動②）。

**書き方の例**（数値はこのフォルダの JSON の値です）：

> 厚生労働省「地域別最低賃金の全国一覧」によりますと、令和8年度の地域別最低賃金（改定額）の全国加重平均は1,177円で、前年度から56円（5.0％）の引上げとなっております。
> また、厚生労働省「民間主要企業春季賃上げ要求・妥結状況」によりますと、令和8年の賃上げ率は5.18％でございました。

**補足**：

- この指針は**労務費**についてのものです。企業物価指数や企業向けサービス価格指数は、指針が例として挙げている資料ではありません。原材料費・エネルギー費・物流費の一般的な動きを示す公表統計として、参考に添える使い方が考えられます。
- 公表統計は、業界や地域全体の動きを示すものです。個々の取引先との取引条件をそのまま決めるものではありません。
- 本ツールは自社のデータと公表統計だけを使います。他社の価格情報は扱いません。
- **ここに書いたのは一般的な情報の紹介で、法的助言ではありません。** 個々の取引への当てはめや、独占禁止法・中小受託取引適正化法（取適法）などの判断は、指針の原文を読んだうえで、公正取引委員会・中小企業庁などの相談窓口や専門家に確認してください。
