# 請求書 自動作成シート かんたん設定ガイド

このシートを使うと、毎月の請求書づくりが次の流れになります。

1. 「明細」シートに、いつ・どの取引先に・何をいくらで、を入力する
2. メニューの「請求書」→「今月分を作成」を押す
3. 取引先ごとの請求書 PDF ができて、Gmail の「下書き」に入る（または、そのまま送信される）

プログラムの知識は必要ありません。最初の設定は 15分ほどで終わります。

---

## 用意するもの
- Google アカウント（Gmail が使えるもの）
- パソコンのブラウザ（Google Chrome がおすすめ）
  - スマホのスプレッドシートアプリでは「請求書」メニューが使えません

---

## ステップ1　スプレッドシートを自分のドライブにコピーする
1. 購入時にお知らせしたリンクを開きます
2. 「コピーを作成」ボタンを押します
3. 名前（例: 請求書 2026）を決めて「コピーを作成」を押します

コピーしたスプレッドシートには、請求書を作るプログラム（スクリプト）も一緒に入っています。

---

## ステップ2　プログラムが入っているか確認する
ほとんどの場合、確認だけで終わります。

1. スプレッドシート上部の「拡張機能」→「Apps Script」を開きます
2. 左の一覧に「コード.gs」（または「Code.gs」）があり、中身の最初のほうに `請求書を自動作成して PDF でメール送信する` という文章があれば OK です。この画面を閉じて、ステップ3へ進んでください

**中身が空っぽ、または別の内容だった場合だけ**、次のように貼り付けます（アップデート版を受け取ったときも同じ手順です）。

1. 「コード.gs」の中身をすべて選んで（Ctrl + A、Mac は command + A）削除します
2. お渡しした `Code.js` をメモ帳などで開き、中身をすべてコピーして貼り付けます
3. 上部の保存ボタン（フロッピーディスクの形）を押します
4. Apps Script の画面を閉じ、スプレッドシートの画面を再読み込み（F5）します

---

## ステップ3　初期設定と「許可」
1. スプレッドシートを開いて数秒待つと、上部のメニューに「請求書」が出ます（出ないときは再読み込み）
2. 「請求書」→「初期設定（シートを用意する）」を押します
3. 「承認が必要です」と出たら「続行」を押し、自分の Google アカウントを選びます
4. 「このアプリは Google で確認されていません」と出たら、
   左下の「詳細」→「（プロジェクト名）（安全ではないページ）に移動」を押します
   - 個人や小さな事業者が作ったプログラムには、必ずこの表示が出ます
   - このプログラムは、あなたの Google アカウントの中だけで動きます。請求書メールを除き、データを外部に送ることはありません（PDF の作成も Google のサービス内で行います）
5. 許可する内容の一覧が出たら、確認して「許可」を押します

| 表示される権限 | 使い道 |
|---|---|
| Gmail のメールの表示・作成・送信など | 請求書メールの下書きを作る・送る・送信済みかどうか確かめる |
| Google ドライブのファイルの表示・作成など | 「請求書」フォルダを作って PDF を保存する |
| このスプレッドシートの表示・編集 | 明細を読む・送信履歴を書く |
| 外部サービスへの接続 | シートを PDF に変換する（Google 自身の機能を呼び出します） |
| メニューやダイアログの表示 | 「請求書」メニューと確認画面を出す |

6. 許可が終わったら、**もう一度**「請求書」→「初期設定（シートを用意する）」を押します（1回目は許可だけで終わることがあります）
   - 「必要なシートはすべてそろっています」と出れば準備完了です

---

## ステップ4　「設定」シートを入力する
B列（値）に入力します。C列は説明です。

| 項目 | 入力する内容 | 例 |
|---|---|---|
| 自社名 | 請求書とメールに載る屋号・会社名（**必須**） | ほしデザイン事務所 |
| 住所 | 請求書に載る住所・電話番号。セルの中で改行するときは Alt + Enter（Mac は option + Enter） | 〒100-0001 東京都千代田区… |
| 登録番号 | インボイスの登録番号。T と13桁の数字。登録していなければ空欄 | T1234567890123 |
| 振込先 | 銀行名・支店・種別・口座番号・名義 | 〇〇銀行 〇〇支店 普通 1234567 ホシ タロウ |
| 支払期限日数 | 空欄なら「翌月末」。数字（例: 30）を入れると、発行日の30日後 | （空欄） |
| 送信モード | 最初は **「下書き」のまま** にしてください | 下書き |
| 件名テンプレ / 本文テンプレ | メールの件名と本文。{取引先名} などの部分は自動で置きかわります | 最初から入っている文面でOK |
| 備考 | 請求書の下に載せる一言（空欄でも可） | お振込手数料は貴社にてご負担… |

件名・本文で使える置きかえ: `{取引先名}` `{敬称}` `{金額}` `{期限}` `{請求書番号}` `{対象月}` `{発行日}` `{自社名}`

件名か本文のどちらかに `{請求書番号}` を必ず残してください（二重送信の確認に使います）。

---

## ステップ5　「取引先」シートを入力する
- サンプルの2行（株式会社サンプル商事・山田 太郎）は、書き換えるか削除してください
- **敬称**: 会社あては「御中」、個人あては「様」（空欄なら御中）
- **メール**: 請求書を送るアドレス。複数のときは「,」（カンマ）で区切ります
- 同じ取引先名を2回登録しないでください

---

## ステップ6　「明細」シートを入力する
1行に1つの品目を入力します。

| 列 | 入力する内容 |
|---|---|
| 日付 | 作業日・納品日。**この日付で「何月分の請求か」が決まります** |
| 取引先名 | 「取引先」シートと**まったく同じ名前**（セルの▼から選べます） |
| 品目 | 請求書に載る内容（例: Webサイト保守（9月分）） |
| 数量 | 数字（1.5 のような小数も可） |
| 単価（税抜） | 消費税を含まない金額。値引きはマイナス（例: -1000） |
| 税区分 | 10% / 8% / 非課税 のどれか（空欄なら 10%） |

- 飲食料品など軽減税率の品目は「8%」にすると、請求書で「※」がつきます
- 消費税は、請求書1枚ごとに税率ごとにまとめて計算し、1円未満は切り捨てます（インボイス制度のルール）

---

## ステップ7　まずは「下書き」で試す（おすすめ）
1. 「請求書」→「下書きだけ作る（送信しない）」を押します
2. 確認画面に、作る件数・取引先・金額・宛先が出ます。内容がよければ「はい」を押します
   - 入力ミスがあると「入力内容を確認してください」と出て、何行目を直せばよいかが表示されます。直してからもう一度押してください
3. 「完了」と出たら、次の3か所を確認します
   - **Gmail の「下書き」**: 件名・本文・添付の PDF
   - **Google ドライブ**: 「マイドライブ ＞ 請求書 ＞ 2026-10」のような月のフォルダに PDF
   - **「送信履歴」シート**: 作った請求書の記録
4. 問題がなければ、Gmail の下書きを開いて、ご自身で「送信」を押してください

明細を直して作り直したいときは、もう一度同じメニューを押すだけです。古い下書きと古い PDF は自動で片づけられ、同じ請求書番号で作り直されます。

---

## ステップ8　毎月の使い方
| やりたいこと | 操作 |
|---|---|
| 今月分をまとめて作る | 「請求書」→「今月分を作成」 |
| 月初に先月分を作る | 「請求書」→「先月分を作成」 |
| 一部の取引先だけ作る | 「取引先」シートで、その取引先の行を選んで（Ctrl / command を押しながらで複数可）→「選択した取引先だけ作成」 |
| 送信前に必ず目で確かめたい | 送信モードは「下書き」のままにして、Gmail から手で送る |
| 確認画面の「はい」で送信まで済ませたい | 「設定」の送信モードを「送信」に変える（**送信は取り消せません**） |

一度送信した請求書は、同じメニューを何度押しても二度と送られません。

## よくある質問

**Q. メニューに「請求書」が出ません。**
A. スプレッドシートを再読み込み（F5）して、10秒ほど待ってください。それでも出ないときは、ステップ2でプログラムが入っているか確認してください。

**Q. 「このアプリは Google で確認されていません」と出て不安です。**
A. Google の審査を受けていない、個人向けのプログラムに必ず出る表示です。プログラムはあなたのアカウントの中だけで動き、データを外部に送りません。許可はあとから取り消せます（Google アカウント ＞ セキュリティ ＞ サードパーティ製のアプリとサービス）。

**Q. 二重に送られてしまうことはありませんか？**
A. 次の仕組みで防いでいます。
- 「送信履歴」シートに「送信済」がある請求書番号は送らない
- Gmail の送信済みフォルダに同じ請求書番号のメールがあれば送らない（下書きを手で送った場合も含む。件名か本文に `{請求書番号}` を残しておいてください）
- メニューを続けて押しても、同時には動かない
- 送る前に必ず確認画面が出る

**Q. 送信済みの請求書を訂正して送り直したいです。**
A. 「送信履歴」シートで、その請求書の行の「状態」を `取消` に書き換えてから、もう一度作成してください。新しい請求書番号で作り直されます（元の番号は欠番になります）。取引先には訂正版である旨をお伝えください。

**Q. 「送信履歴」の行は消してもいいですか？**
A. 消さないでください。二重送信の防止と請求書番号の管理に使っています。

**Q. インボイス（適格請求書発行事業者）の登録をしていません。使えますか？**
A. 使えます。「設定」の登録番号を空欄にしてください。請求書に登録番号の行が出なくなります（その場合、適格請求書にはなりません）。

**Q. 8%（軽減税率）の品目がありません。**
A. そのままお使いください。請求書の税率別の内訳には、使った税率だけが表示されます。

**Q. 源泉徴収税を差し引いた請求書は作れますか？**
A. 標準では対応していません。

**Q. 請求書のデザインを変えたいです。**
A. 「請求書テンプレ」シートの文字の色・大きさ・フォント、ロゴ画像の追加は自由に変えられます。ただし、**行や列を追加・削除したり、セルの位置を動かしたりすると、金額などが正しい場所に入らなくなります**。レイアウトを変えたいときはご相談ください。

**Q. 明細が多くて1枚に収まりません。**
A. 1枚の請求書の明細が15行を超えると、自動で行を増やします。PDF が2ページになることがあります。

**Q. 一度に何件まで作れますか？**
A. 目安は1回30件ほどです。時間がかかりすぎそうなときは途中で止まり、「時間切れで未処理」と表示されます。もう一度同じメニューを押すと続きを作ります（送信済みの分は自動で飛ばします）。
なお、Gmail には1日に送れる通数の上限があります（無料の Gmail はおよそ100通、Google Workspace はおよそ1,500通）。

**Q. 「PDF の書き出しに失敗しました」と出ました。**
A. Google 側が混み合っていることがあります。数分おいてから、もう一度実行してください。うまくいかなかった請求書は「送信履歴」に「エラー」として記録されます。

**Q. 日付が正しいのに「今月の明細がありません」と出ます。**
A. 「ファイル」→「設定」で、タイムゾーンが「(GMT+09:00) 東京」になっているか確認してください。また、日付のセルが文字ではなく日付として入力されているか（セルを選んだとき右寄せになっているか）も確認してください。
