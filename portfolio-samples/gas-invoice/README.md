# 請求書の自動作成・PDFメール送信（Google Apps Script）

スプレッドシートに明細を入力しておくと、月ごと・取引先ごとに請求書を作り、PDF にして Gmail で送る（または下書きに保存する）テンプレートです。フリーランス・小規模事業者向けで、インボイス制度（適格請求書）の記載事項と消費税の端数処理に対応しています。

購入者向けのやさしい手順書は [SETUP_GUIDE.md](SETUP_GUIDE.md) にあります。

## できること
| メニュー「請求書」 | 動き |
|---|---|
| 今月分を作成 | 今月の明細を取引先ごとにまとめて請求書 PDF を作り、「設定」の送信モードに従って Gmail の下書きに保存、または送信 |
| 先月分を作成 | 同じことを先月分で行う（月初にまとめて請求する場合） |
| 選択した取引先だけ作成 | 「取引先」か「明細」シートで選んだ行の取引先だけ、今月分を作る |
| 下書きだけ作る（送信しない） | 送信モードが「送信」でも、今月分を下書き保存だけにする |
| 初期設定（シートを用意する） | 必要なシートと請求書のレイアウトを作る（すでにあるシートは触らない） |

- PDF はマイドライブの `請求書/YYYY-MM` フォルダに保存
- 請求書番号は `INV-202609-001` 形式（月ごとの連番）。同じ月・同じ取引先なら、作り直しても同じ番号
- **二重送信の防止**: 「送信履歴」シートに記録し、送信済みの番号は送らない。Gmail の送信済みフォルダも請求書番号で検索する（件名か本文に `{請求書番号}` がある前提）。同時実行はロックで防ぐ
- 実行前に、件数・金額・宛先の確認ダイアログを出す。**初期状態は下書きモード**（送信しない）
- 下書きを作り直すと、古い下書きと古い PDF は自動で片づける
- 入力ミス（日付・数量・単価・税区分・未登録の取引先・メールアドレス・登録番号）は、作成前に行番号つきでまとめて表示し、1件も作らずに止める
- 件数が多くて実行時間（6分）の上限に近づいたら途中で止め、再実行で続きから作る

## 消費税の計算（適格請求書のルール）
- 明細の金額 = 数量 × 単価（税抜）。1円未満は切り捨て
- 1枚の請求書の中で税率（10% / 8%）ごとに金額を合計し、**税率ごとに1回だけ**消費税を計算して1円未満を切り捨てる
  - 例: 10% の明細が 1,005円 と 1,005円 → 2,010円 × 10% = **201円**（1行ずつ計算して足すと 200円になってしまう）
- 非課税の明細は消費税 0円。軽減税率（8%）の品目には「※」をつけ、注記を入れる
- 請求書に載せる項目: 発行者名・登録番号・取引日・品目・税率ごとの対象金額と消費税額・宛名
- 発行日は対象月の末日（月末締め）。支払期限は翌月末（「設定」で「発行日の◯日後」に変更可）

## シート構成
| シート | 列 / 内容 |
|---|---|
| 取引先 | 取引先名 / 敬称（御中・様）/ メール（カンマ区切りで複数可） |
| 明細 | 日付 / 取引先名 / 品目 / 数量 / 単価（税抜）/ 税区分（10% / 8% / 非課税。空欄は 10%） |
| 設定 | 自社名・住所・登録番号・振込先・支払期限日数・送信モード・件名テンプレ・本文テンプレ・備考 |
| 請求書テンプレ | 請求書のレイアウト（A4 縦）。1件ごとにコピーして値を入れ、PDF にしてから消す |
| 送信履歴 | 日時 / 請求書番号 / 対象月 / 取引先名 / 宛先 / 合計金額 / 状態 / PDF / 下書きID |

件名・本文テンプレで使える差し込み: `{取引先名}` `{敬称}` `{金額}` `{期限}` `{請求書番号}` `{対象月}` `{発行日}` `{自社名}`

送信済みの請求書を訂正して出し直すときは、「送信履歴」のその行の状態を `取消` に書き換えます。次回は新しい番号で作り直します（元の番号は欠番）。

## 設定手順
1. 新しいスプレッドシートを作り、「拡張機能」→「Apps Script」を開く
2. `Code.js` の中身を貼り付けて保存する
   - 任意: 「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにし、このフォルダの `appsscript.json` に置き換えると、権限が下の表のものだけになる
3. エディタで `setupSheets` を選んで実行し、権限を許可する → 5つのシートができる
4. スプレッドシートを開き直すと、メニューに「請求書」が出る
5. 「設定」に自社名・登録番号・振込先を入れ、「取引先」「明細」のサンプル行を書き換える
6. 「請求書」→「今月分を作成」。下書きモードなので、Gmail の下書きと Drive の PDF を確認する
7. 問題なければ、「設定」の送信モードを「送信」にする

販売用には、手順 3 まで済ませたスプレッドシートを「コピーを作成」リンク（`.../copy`）で配ると、購入者はスクリプトごとコピーできます。

### 権限（appsscript.json）
| スコープ | 使う理由 |
|---|---|
| `spreadsheets.currentonly` | このスプレッドシートだけを読み書きする |
| `script.container.ui` | メニューと確認ダイアログ |
| `script.external_request` | シートを PDF に書き出す（`UrlFetchApp` で Google の書き出し URL を呼ぶ） |
| `drive` | `請求書/YYYY-MM` フォルダを作って PDF を保存する |
| `https://mail.google.com/` | Gmail の下書き作成・送信・送信済みの確認（`GmailApp` はこのスコープが必要） |

## テスト
Google のサービスを使わない計算ロジック（消費税の端数処理、取引先ごとのまとめ、対象月の絞り込み、請求書番号、差し込み、入力チェック）は Node でテストできます。
```bash
npm test
```
PDF の書き出し・Drive・Gmail の部分は GAS 上で動かして確認します（下書きモードなら送信はされません）。

## カスタマイズ
- 請求書番号の頭（`INV`）・保存先フォルダ名・敬称の初期値・空欄の税区分は `CONFIG` にまとめてあります
- 列の並びは `COL`、請求書レイアウトのセル位置は `TPL`。テンプレのセルを動かしたら `TPL` の番地を合わせます（色・フォント・ロゴ画像の追加は自由）
- 明細が 15 行を超えると、テンプレに行を足して下の欄をずらします（行数は `TPL.itemRows`）
- 締め日を末日以外にする、源泉徴収税を差し引く、などは `planInvoices` / `calcInvoiceTotals` を変えます（標準では未対応）
- 確認ダイアログを出すため、時間主導型トリガーでの自動実行には対応していません。対応する場合は `runInvoices` の確認部分を外します
