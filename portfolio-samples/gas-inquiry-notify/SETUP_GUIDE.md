# 導入ガイド：問い合わせフォームの自動返信＋チャット通知＋対応管理

このガイドは、プログラミングの経験がない方でも導入できるように、画面の操作を順番に説明しています。

- **所要時間**: 30分ほど（通知先のチャットを準備する時間を含む）
- **必要なもの**: Googleアカウント（Gmail または Google Workspace）
- **あると便利なもの**: 通知に使うチャット（Slack / Discord / Chatwork のどれか）。チャットを使わなくても、自動返信と対応管理は使えます

> 画面のボタン名は、2026年10月時点のものです。各サービスの更新で表記が少し変わることがあります。

## 0. 全体の流れ

```
お客様がフォームを送信
   │
   ├─ スパム疑い？（メールアドレスが不正／NGワードを含む）
   │     └─ はい → 対応状況を「スパム疑い」にして終了（返信・通知はしない）
   │
   ├─ お客様に自動返信メール（「予約」「見積」など種別ごとの文面）
   ├─ Slack / Discord / Chatwork に新着通知
   └─ 対応状況を「未対応」にして、処理ログに結果を記録

毎朝9時ごろ
   └─ 「未対応」のまま24時間たった問い合わせをチャットでお知らせ
```

## 1. Googleフォームを作る

1. https://forms.google.com を開き、「空白のフォーム」を作ります
2. 次の質問を作ります。**質問のタイトルは、下の表と同じ文字にする**と、あとの設定がそのまま使えます

| 質問のタイトル | 質問の形式 | 必須 | メモ |
|---|---|---|---|
| お名前 | 記述式 | ○ | |
| メールアドレス | 記述式 | ○ | 下の「入力ミスを減らす設定」がおすすめ |
| 電話番号 | 記述式 | | |
| お問い合わせ種別 | ラジオボタン | ○ | 選択肢は「予約」「見積」「その他」 |
| ご希望日時 | 記述式 | | 予約を受ける場合 |
| お問い合わせ内容 | 段落 | ○ | |

**入力ミスを減らす設定（メールアドレス）**
質問「メールアドレス」の右下の「︙」→「回答の検証」→「テキスト」「メールアドレス」を選びます。形式が違うと送信できなくなるので、返信が届かない事故を防げます。

> フォームの「設定」→「回答」→「メールアドレスを収集する」を使う方法でもかまいません。その場合は、質問「メールアドレス」は作りません（列の名前が同じ「メールアドレス」になるので、設定はそのままで動きます）。

> 質問のタイトルを表と違う名前にした場合は、「5. 設定シートを編集する」で項目名を合わせます。質問は自由に増やせます（増やした質問も通知に自動で載ります）。

## 2. 回答をスプレッドシートにつなぐ

1. フォームの編集画面の上にある「回答」タブを開きます
2. 「スプレッドシートにリンク」（緑のアイコン）を押します
3. 「新しいスプレッドシートを作成」を選び、「作成」を押します
4. スプレッドシートが開き、下のタブに「フォームの回答 1」というシートができていれば完了です

---

## 3. スクリプトを貼り付ける

1. 手順2のスプレッドシートで、メニューの「拡張機能」→「Apps Script」を開きます
2. 左上の「無題のプロジェクト」をクリックし、「問い合わせ自動化」など分かりやすい名前にします（権限の確認画面にこの名前が出ます）
3. 左の「ファイル」にある「コード.gs」を開き、最初から書かれている `function myFunction() { … }` を**すべて消します**
4. 同梱の `Code.js` をメモ帳などのテキストエディタで開き、**全部コピーして貼り付け**ます
5. 上のフロッピーディスクのアイコン（プロジェクトを保存）を押します（Ctrl＋S／⌘＋S でも可）

**（おすすめ）マニフェストも差し替える**
タイムゾーンが日本時間になり、許可する権限が必要最小限になります。

1. 左の歯車アイコン「プロジェクトの設定」を開きます
2. 「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェックを入れます
3. 左の「エディタ」（`< >` のアイコン）に戻り、増えた `appsscript.json` を開きます
4. 中身をすべて消して、同梱の `appsscript.json` の中身を貼り付け、保存します

## 4. 初期設定を実行する（権限の承認）

1. Apps Script エディタの上部にある関数の選択欄（「myFunction」などと表示されている所）で **`setupAll`** を選び、「実行」を押します
2. 「承認が必要です」と出たら「権限を確認」を押します
3. 使う Googleアカウントを選びます
4. 「このアプリは Google で確認されていません」と出たら、左下の「詳細」→「問い合わせ自動化（安全ではないページ）に移動」を押します
   - これは、Google の審査を受けていない自作のスクリプトに必ず出る表示です。このスクリプトは、このスプレッドシート以外のファイルには触れません
5. 権限の一覧が出たら「許可」を押します（チェックボックスが出た場合は「すべて選択」にしてから「続行」）
6. 画面下の実行ログに「初期設定が完了しました」と出れば成功です
7. スプレッドシートに戻ってページを再読み込み（F5）すると、メニューに **「問い合わせ管理」** が出ます

このとき、スプレッドシートに次のものが自動で作られます。

- 「設定」シート、「返信テンプレート」シート
- 「フォームの回答 1」シートの右端に「対応状況」「担当」「処理ログ」の列
- フォーム送信時と毎朝9時に自動で動く設定（トリガー）

**許可した権限の使いみち**

| 画面の表示（例） | 使いみち |
|---|---|
| このアプリケーションが接続されているスプレッドシートの表示と管理 | 回答の読み取り、対応状況・処理ログの書き込み |
| ユーザー本人としてメールを送信 | お客様への自動返信 |
| ユーザーがいないときにこのアプリケーションを実行できるようにする | フォーム送信時・毎朝の自動実行 |
| 外部サービスへの接続 | Slack / Discord / Chatwork への通知 |
| 外部アプリケーション内でサードパーティのウェブコンテンツを表示、実行 | メニューと確認画面の表示 |

> `setupAll` は何度実行しても大丈夫です。入力済みの設定は消えず、トリガーも1つにまとまります。

## 5. 「設定」シートを編集する

B列（値）を書き換えます。「する／しない」の項目はプルダウンで選べます。

| 項目 | 例 | 説明 |
|---|---|---|
| 店舗名 | カフェ星 | 返信メールの `{店舗名}` に入ります |
| 回答シート名 | フォームの回答 1 | 回答が入るシートのタブ名 |
| お名前の項目名 | お名前 | フォームの質問のタイトルと**一字一句同じ**にします |
| メールアドレスの項目名 | メールアドレス | 同上 |
| 種別の項目名 | お問い合わせ種別 | 返信の文面を切り替える質問。切り替えない場合は空欄 |
| 自動返信 | する | お客様への自動返信メール |
| 差出人名 | カフェ星 | お客様のメールに表示される差出人の名前 |
| 返信先アドレス | info@example.com | お客様が「返信」したときの宛先（空欄なら送信元と同じ） |
| 自動返信のBCC | owner@example.com | 返信メールの控えを受け取るアドレス（空欄なら送らない） |
| 署名 | （複数行） | 返信メールの `{署名}` に入ります |
| Slack通知 ／ Slack Webhook URL | する ／ https://hooks.slack.com/… | 手順7-1 |
| Discord通知 ／ Discord Webhook URL | する ／ https://discord.com/api/webhooks/… | 手順7-2 |
| Chatwork通知 ／ ChatworkルームID | する ／ 123456789 | 手順7-3（トークンはシートに書きません） |
| 通知の文字数上限 | 500 | チャット通知に載せる、1項目あたりの最大文字数 |
| 未対応リマインド | する | 毎朝9時ごろのお知らせ |
| リマインド対象（経過時間） | 24 | 何時間「未対応」のままならお知らせするか |
| NGワード | カジノ,相互リンク | これを含む送信は「スパム疑い」にします（カンマ区切り） |
| 担当者リスト | 店長,佐藤,鈴木 | 「担当」列のプルダウンに出す名前（カンマ区切り） |

**入力のコツ**
- セルの中で改行するには、Windows は Ctrl＋Enter、Mac は ⌘＋Enter を押します
- NGワードは、大文字・小文字、全角・半角を区別しません（「casino」で「ＣＡＳＩＮＯ」も見つかります）。短すぎる言葉は普通のお問い合わせにも引っかかるので注意してください
- 担当者リストを変えたら、メニュー「問い合わせ管理」→「初期設定（最初に1回）」をもう一度実行すると、既存の行のプルダウンも新しくなります

書き終わったら、メニュー「問い合わせ管理」→ **「設定をチェック」** を押してください。質問名の食い違い、URLの形式の間違い、テンプレートの差し込み名のタイプミスなどを教えてくれます。

## 6. 返信テンプレートを編集する

「返信テンプレート」シートの1行が、1種類の返信メールです。

| 種別 | 件名 | 本文 |
|---|---|---|
| 予約 | 【{店舗名}】ご予約のお問い合わせを受け付けました（受付番号 {受付番号}） | {お名前} 様 … |
| 見積 | … | … |
| その他 | … | … |

**差し込み**
`{` `}` で囲んだ部分が、自動で置き換わります。

| 書き方 | 入るもの |
|---|---|
| `{お名前}` `{ご希望日時}` など | フォームの、そのタイトルの質問への回答 |
| `{店舗名}` `{署名}` | 「設定」シートの値 |
| `{受付番号}` | 受付日時から作る番号（例: 20261006-090512） |
| `{受付日時}` | 例: 2026/10/06 09:05 |

- フォームにない名前を書くと、その部分は空欄で送られます（「設定をチェック」で見つけられます）
- 全角の `｛お名前｝` でも動きます

**どのテンプレートが使われるか**
1. フォームの「お問い合わせ種別」の回答と、A列「種別」が同じ行
2. なければ、回答に種別の言葉が含まれる行（例: 回答「ご予約」→「予約」の行）
3. なければ「その他」の行

種別を増やすときは、行を足してフォームの選択肢にも同じ言葉を加えます。種別で切り替えない場合は、「設定」の「種別の項目名」を空欄にすると、いつも「その他」の行が使われます。

## 7. 通知先のチャットを準備する

使うものだけ準備してください。複数を同時に使うこともできます。

### 7-1. Slack（Incoming Webhook）

1. パソコンのブラウザで https://api.slack.com/apps を開き、Slack にログインします
2. 「Create New App」→「From scratch」を選びます
3. 「App Name」に「問い合わせ通知」など、ワークスペースを選んで「Create App」を押します
4. 左のメニュー「Incoming Webhooks」を開き、右上のスイッチ「Activate Incoming Webhooks」を **On** にします
5. ページ下の「Add New Webhook to Workspace」（「Add New Webhook」と表示される場合もあります）を押し、通知を流したいチャンネルを選んで「許可する」を押します
6. 表示された `https://hooks.slack.com/services/…` の URL を「Copy」でコピーします
7. 「設定」シートの「Slack Webhook URL」に貼り付け、「Slack通知」を「する」にします

> ワークスペースによっては、アプリの追加に管理者の承認が必要です。
> この URL を知っている人は誰でもそのチャンネルに投稿できます。人に見せたり、公開の場所に貼ったりしないでください。

### 7-2. Discord（ウェブフック）

1. 通知を流したいチャンネル名にマウスを乗せ、歯車アイコン「チャンネルの編集」を押します
2. 「連携サービス」→「ウェブフックを作成」を押します（すでにある場合は「ウェブフックを確認」）
3. 作られたウェブフックを開き、名前（例: 問い合わせ通知）と投稿先のチャンネルを確認します。変えた場合は「変更を保存」を押します
4. 「ウェブフックURLをコピー」を押します
5. 「設定」シートの「Discord Webhook URL」に貼り付け、「Discord通知」を「する」にします

> ウェブフックを作るには、そのサーバーで「ウェブフックの管理」の権限が必要です。
> この URL も、知っている人は誰でも投稿できます。取り扱いに注意してください。

### 7-3. Chatwork（APIトークン＋ルームID）

**APIトークンを取得して登録する**
1. Chatwork にログインし、右上の自分の名前（利用者名）→「サービス連携」を開きます
2. 左のメニュー「APIトークン」を開き、パスワードを入力して「表示」を押します
3. 表示されたトークンをコピーします
4. スプレッドシートのメニュー「問い合わせ管理」→ **「Chatworkトークンを登録」** を押し、貼り付けて「OK」を押します

> トークンはシートには書かれず、スクリプトの中（スクリプトプロパティ）に保存されます。スプレッドシートを共有しても、相手には見えません。
> 組織で契約しているプランでは、管理者が API の利用を許可していないとトークンを表示できないことがあります。

**ルームIDを設定する**
5. 通知を流したいグループチャットを開きます
6. ブラウザの URL の末尾 `#!rid123456789` の **数字の部分** をコピーし、「設定」シートの「ChatworkルームID」に貼り付けます（URL をそのまま貼っても数字だけ取り出します）
7. 「Chatwork通知」を「する」にします

> 通知は、トークンを発行した人の名前で投稿されます。自分が投稿したメッセージは自分には未読にならないため、店長ご本人のトークンを使うと新着に気づきにくくなります。通知専用の Chatwork アカウントを作り、そのアカウントのトークンを使うのがおすすめです（そのアカウントをルームのメンバーに入れてください）。

## 8. 動作テスト

順番に確認すると、問題がどこにあるか分かりやすくなります。

1. **設定のチェック**: メニュー「問い合わせ管理」→「設定をチェック」。指摘があれば直します
2. **チャットのテスト**: 「テスト通知を送る（チャット）」を押します
   - 各チャットに「【テスト通知】問い合わせ通知の設定ができました」が届けば成功です
   - 画面に「Slack: OK」などと結果が出ます。「失敗」の場合は [よくある質問](#q-チャットに通知が来ない) を見てください
3. **返信メールのテスト**: 「自動返信のテストメールを送る」を押し、自分のメールアドレスを入力します
   - テンプレートの数だけ、件名に「[テスト]」がついたメールが届きます。文面と差し込みを確認します
4. **本番と同じ流れのテスト**: フォームの編集画面の右上にある目のアイコン（プレビュー）を開き、自分のメールアドレスで実際に送信します
   - [ ] 自動返信メールが届く（迷惑メールフォルダも確認）
   - [ ] チャットに「【新着問い合わせ】…」が届く。通知の「スプレッドシートを開く」でその行に移動できる
   - [ ] 回答シートの「対応状況」が「未対応」になり、「処理ログ」に「返信: 送信済（予約）／Slack: OK」などと記録される
5. **スパム判定のテスト**: NGワード（例: カジノ）を「お問い合わせ内容」に入れて送信します
   - [ ] 「対応状況」が「スパム疑い」になり、返信メールもチャット通知も来ない
6. テストの行は、確認が終わったら削除してかまいません

> Apps Script エディタで `onFormSubmit` を直接「実行」しても動きません（フォームの送信で動く仕組みのため）。テストは上の方法で行ってください。

## 9. 毎日の使い方

1. 新着がチャットに届いたら、通知のリンクからスプレッドシートを開きます
2. 対応を始めたら「対応状況」を「対応中」に、「担当」に自分の名前を選びます
3. 対応が終わったら「完了」にします
4. 毎朝9時ごろ、「未対応」のまま24時間（設定で変更可）たった問い合わせがチャットに届きます
5. 「スパム疑い」の行もときどき目を通し、本物のお問い合わせなら「未対応」に変えて対応してください

対応状況は色分けされます（未対応＝赤、対応中＝黄、完了＝緑、スパム疑い＝灰）。フィルタ（データ →「フィルタを作成」）で「未対応」だけを表示すると便利です。

## 10. よくある質問

### Q. 自動返信メールが届かない
- お客様（またはテストした自分）の **迷惑メールフォルダ** を確認してください
- 回答シートの「処理ログ」を確認してください
  - 「返信: 失敗（…）」→ かっこの中が理由です
  - 「スパム疑いのため返信・通知なし」→ メールアドレスの形式か NGワードが原因です
  - 何も書かれていない → トリガーが動いていません。`setupAll` をもう一度実行してください
- 「メールアドレスの項目名」がフォームの質問のタイトルと同じか、「設定をチェック」で確認してください
- Google には1日に送れるメールの上限があります（無料の Gmail アカウントは1日100通、Google Workspace は1日1,500通が目安。Google の仕様で変わることがあります）。上限に達した日は「処理ログ」に記録され、返信は送られません

### Q. 送信元のメールアドレスは？変えられますか？
`setupAll` を実行した（トリガーを作った）Googleアカウントのアドレスから送られます。
- お客様の返信をお店のアドレスで受けたい場合は、「返信先アドレス」にお店のアドレスを入れてください
- 送信元そのものをお店のアドレスにしたい場合は、お店の Googleアカウントでフォームとスプレッドシートを作り、そのアカウントで導入してください

### Q. チャットに通知が来ない
まず「Slack通知」などが「する」になっているか確認し、「テスト通知を送る」の結果か「処理ログ」を見てください。

| 表示 | 主な原因と対処 |
|---|---|
| Webhook URL が未設定です | 「設定」シートに URL を貼り付けてください |
| APIトークンが未登録です | メニュー「Chatworkトークンを登録」から登録してください |
| ルームIDが未設定です | 「ChatworkルームID」に数字を入れてください |
| Slack: 失敗（HTTP 404 / 403 …） | URL の貼り間違い、または Slack のアプリやチャンネルが削除された。手順7-1で URL を作り直してください |
| Discord: 失敗（HTTP 404 / 401 …） | ウェブフックが削除された、または URL の一部が欠けている。手順7-2で作り直してください |
| Chatwork: 失敗（HTTP 401） | トークンの間違い、またはトークンを再発行して古いものが無効になった |
| Chatwork: 失敗（HTTP 403 / 404） | ルームIDの間違い、またはトークンの持ち主がそのルームのメンバーでない（書き込み権限がない） |

### Q. 普通のお問い合わせが「スパム疑い」になった
「処理ログ」に理由が書かれています。NGワードが原因なら「設定」シートの NGワードを見直してください。
そのお問い合わせは「対応状況」を「未対応」に変えて対応してください（自動返信と通知はあとから自動では送られないので、必要ならお客様へ手動で連絡してください）。

### Q. フォームの質問を増やした・名前を変えた
増やした質問は、自動でチャット通知に載ります。名前を変えた質問を「設定」の項目名や返信テンプレートの `{ }` で使っている場合は、そちらも同じ名前に直してから「設定をチェック」を押してください。

### Q. リマインドが9時ちょうどに来ない
Google の仕組みで、前後15分ほどずれることがあります。時刻そのものを変えたい場合は、`Code.js` の上の方にある `reminderHour: 9` の数字を変えて保存し、`setupAll` をもう一度実行してください。

### Q. リマインドを止めたい
「設定」シートの「未対応リマインド」を「しない」にしてください。メニュー「未対応リマインドを今すぐ送る」からは、いつでも手動で送れます。

### Q. 同じ通知が2回届く
同じスクリプトを2つのプロジェクトに入れている可能性があります。Apps Script エディタの左にある時計のアイコン「トリガー」を開き、`onFormSubmit` が1つだけか確認してください（このスクリプトの `setupAll` は、何度実行してもトリガーを1つにまとめます）。

### Q. 導入する前からある回答はどうなりますか？
「対応状況」が空欄のままになり、リマインドの対象にはなりません。対象にしたい行は「未対応」を選んでください。

### Q. 回答が1,000件を超えたら？
新しい行にもプルダウンは自動でつきます。色分けがつかなくなった場合は、`setupAll` をもう一度実行してください。

### Q. Webhook URL もシートに書きたくない
スプレッドシートをほかの人と共有する場合などにおすすめの方法です。Apps Script エディタの「プロジェクトの設定」→「スクリプト プロパティ」で、次の名前で URL を登録すると、シートより優先して使われます（シートの URL 欄は空欄でかまいません）。
- `SLACK_WEBHOOK_URL`
- `DISCORD_WEBHOOK_URL`

### Q. 使うのをやめたい
1. Apps Script エディタの「トリガー」（時計のアイコン）で、`onFormSubmit` と `sendDailyReminder` を削除します
2. Chatwork を使っていた場合は、メニュー「Chatworkトークンを登録」で空欄のまま「OK」を押してトークンを消し、Chatwork 側でもトークンを再発行（無効化）します
3. Slack のアプリ、Discord のウェブフックも、不要なら削除してください

### Q. 「安全ではないページ」と表示されるのが心配です
Google の審査を受けていない、個人や会社で作ったスクリプトには必ず出る表示です。動きはすべて `Code.js` に書かれており、外部に送るのは「設定」シートで指定した Slack・Discord・Chatwork の宛先だけです。
