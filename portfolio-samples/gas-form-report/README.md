# 経費申請フォームの自動化（Google Apps Script）

Googleフォームで受け付けた経費申請を、承認者への通知から月次集計までまとめて自動化するサンプルです。

## できること
| タイミング | 動き |
|---|---|
| フォームが送信されたとき | 承認者に「誰が・いくら・何に」をメールで通知 |
| 毎月1日 9時 | 先月分を「部署 × 経費区分」で集計したシート `集計_YYYY-MM` を作り、合計をメールで報告 |
| 手動（`buildThisMonthReport`） | 今月の途中経過をシートに出す |

金額の入力ゆれ（`¥3,000` / `800円` / `1200`）は自動で数値にそろえます。

## 設定手順
1. Googleフォームを作る。項目は「氏名 / 部署 / 経費区分 / 金額 / 内容」
2. フォームの「回答」→「スプレッドシートにリンク」で回答シートを作る
3. スプレッドシートの「拡張機能」→「Apps Script」を開き、`Code.js` の中身を貼り付ける
4. `CONFIG` のメールアドレスを書き換える
5. `setupTriggers` を1回実行し、権限を許可する

## テスト
Google のサービスを使わない集計ロジックは Node でテストできます。
```bash
npm test
```

## 実案件への流用
- 列の並びは `COL`、送り先や時刻は `CONFIG` と `setupTriggers` にまとめてあります
- 集計の切り口（担当者別・案件別など）は `summarizeMonth` を変えるだけで対応できます
